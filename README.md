# AI-Powered Recruitment & Assessment Automation Pipeline 🚀

An automated recruitment screening and assessment workflow built using **n8n**, **Python**, **FastAPI**, and deployed with a modern interactive frontend.

---

## 🛠️ Tech Stack & Tools
* **Automation Workflow:** n8n (Gmail Trigger, Code Nodes, Webhooks, Gmail Sender)
* **Backend & Processing:** Python, FastAPI
* **Frontend:** HTML5, CSS3, JavaScript (Deployed on Vercel)
* **Version Control:** Git & GitHub

---

## 📋 Project Workflow
1. **Resume Ingestion:** Automatically polls and triggers via Gmail when a candidate's resume is received.
2. **Parsing & Filtering:** Extracts resume content, parses text data, and evaluates candidate qualifications based on predefined keyword criteria (Data Science / Data Analyst roles).
3. **Automated Notification:** Instantly sends an HTML-formatted confirmation email to the qualified candidate with a secure link to the technical assessment quiz.
4. **Assessment Portal:** A clean, interactive frontend hosted on Vercel where candidates complete their technical evaluation.

---

## 🚀 Deployment
* **Frontend:** Hosted live on **Vercel**
* **Automation Pipeline:** Orchestrated locally/cloud via **n8n**
